# SDP Endterm Lab

Responsive quiz website for AITU Software Design Patterns, Lectures 6–10.

- 67 multiple-choice questions, including 20 original questions from the provided preparation guide.
- 40-question mock exam with 50-minute timer.
- Topic practice, guide practice, review of mistakes.
- Local progress history and scoring.

## GitHub Pages

Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.

Site URL after Pages deployment: https://fara1009.github.io/Sdp/

No build step or server required. Open `index.html` locally or host the files as static assets.
